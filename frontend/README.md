# My Library — ชั้นหนังสือส่วนตัว

เว็บแอปสำหรับบันทึก **หนังสือที่เรามี** และ **หนังสือที่เราอยากได้** พร้อมหน้าล็อกอินที่บันทึกประวัติการเข้าใช้งานไว้ให้ดูย้อนหลังได้

สร้างด้วย React 19 + Vite เชื่อมต่อ REST API จาก backend (Express + PostgreSQL) — ข้อมูลบัญชี หนังสือ และประวัติการเข้าใช้งานถูกเก็บในฐานข้อมูล

## ฟีเจอร์

- **สมัครสมาชิก / เข้าสู่ระบบ** — แต่ละบัญชีมีชั้นหนังสือของตัวเอง รหัสผ่านถูก hash ฝั่งเซิร์ฟเวอร์ด้วย scrypt และยืนยันตัวตนด้วย session token
- **บันทึกประวัติการเข้าใช้งาน** — เก็บ login / logout / สมัครสมาชิก พร้อมวันเวลาและอุปกรณ์ (สูงสุด 100 รายการ)
- **ชั้นหนังสือของฉัน** — เพิ่ม แก้ไข ลบ ค้นหา กรองตามหมวดหมู่ และเรียงลำดับ
- **รายการที่อยากได้** — จดเล่มที่ตั้งใจจะอ่าน แล้วย้ายเข้าชั้นหนังสือได้ในคลิกเดียว
- **แดชบอร์ด** — สรุปจำนวนหนังสือ คะแนนเฉลี่ย หนังสือที่เพิ่มเดือนนี้ และรายการล่าสุด
- **โหมดสว่าง / โหมดมืด** — จำค่าที่เลือกไว้
- **รองรับมือถือ** — เปลี่ยนเมนูด้านข้างเป็นแถบนำทางด้านล่าง

## เริ่มใช้งาน

ต้องเริ่ม backend ก่อน (ดูรายละเอียดใน `README.md` ที่ root ของโปรเจกต์) จากนั้น

```bash
cd frontend
npm install
npm run dev
```

เปิด `http://localhost:5173/`

ถ้า API ไม่ได้อยู่ที่ `http://localhost:5000` ให้สร้างไฟล์ `.env` และตั้ง `VITE_API_URL`

### บัญชีตัวอย่าง

กดปุ่ม **“ลองใช้งานด้วยบัญชีตัวอย่าง”** ในหน้าเข้าสู่ระบบ หรือใช้

- ชื่อผู้ใช้: `demo`
- รหัสผ่าน: `demo1234`

บัญชีตัวอย่างจะมีหนังสือให้ลอง 10 เล่ม (มีอยู่แล้ว 6 เล่ม / อยากได้ 4 เล่ม)

## โครงสร้างโปรเจกต์

```
frontend/src/
├─ App.jsx                 # สลับหน้า Login / App ตาม session
├─ index.css               # ธีมและสไตล์ทั้งหมด
├─ components/
│  ├─ AppShell.jsx         # เลย์เอาต์หลัก + เมนู + จัดการ modal/toast
│  ├─ BookCard.jsx         # การ์ดหนังสือ
│  ├─ BookModal.jsx        # ฟอร์มเพิ่ม / แก้ไขหนังสือ
│  ├─ BookCollection.jsx   # หน้ารวมหนังสือ + ค้นหา/กรอง/เรียง
│  ├─ ConfirmDialog.jsx    # ยืนยันการลบ
│  ├─ Icon.jsx, Stars.jsx, Toast.jsx
├─ context/AuthContext.jsx # ระบบบัญชี, session และประวัติการเข้าใช้งาน
├─ hooks/useBooks.js       # CRUD หนังสือของแต่ละผู้ใช้
├─ lib/
│  ├─ storage.js           # localStorage (token/ธีม) + ข้อมูลอุปกรณ์
│  ├─ format.js            # จัดรูปแบบวันที่/เวลา/ตัวย่อ
│  └─ api.js               # เรียก REST API ของ backend
└─ pages/
   ├─ AuthPage.jsx
   ├─ Dashboard.jsx
   └─ Activity.jsx
```

## หมายเหตุด้านความปลอดภัย

ระบบนี้ออกแบบสำหรับใช้งานส่วนตัว รหัสผ่านถูก hash ด้วย scrypt ฝั่งเซิร์ฟเวอร์ และ session token ถูกเก็บใน `localStorage` ของเบราว์เซอร์ หากต้องการใช้งานหลายเครื่องให้ตั้งค่า backend และฐานข้อมูล PostgreSQL ร่วมกัน — ข้อมูลจะซิงก์ผ่าน API
